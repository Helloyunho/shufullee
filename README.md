# Shufullee

Generate a playlist of songs with a specific duration.

## How it works

Uhhhh... it just iterates through Apple Music playlists and adds/removes songs until the total duration of the playlist is equal to the specified duration

## Usage

1. Clone the repository
2. Install dependencies with any Node.js package manager
3. Rename `.dev.vars.example` to `.dev.vars` and fill in the required environment variables (You need Apple Developer Membership to get the required keys)
4. Run the development server with `npm run dev` or `yarn dev` or `pnpm dev` or whatever
